# Bramblekeep Name Plan

Linked prompts file: `prompts/2026-10-28-115022-game-name-prompts.md`
Linked learnings file: `learnings/2026-10-28-115022-game-name-learnings.md`

## Goal

Replace the working title "Castle Adventure" with a name that captures what the
game is: a shared world where heroes storm a castle defended by living garden
creatures, and whose gate levers grow back. Apply the chosen name to the
identifiers, packages, menu text and docs that name the game, and leave the
historical records as they were.

## Approach

1. Read the brief, the direction docs, the in-game text and the screenshots to
   find the game's essence.
2. Propose a recommended name with reasons, alternatives with trade-offs, and a
   search for existing games with the same names.
3. The user chose Bramblekeep.
4. Rename the game: id, title and storage prefix in `game/game.json`; the menu
   tagline; the Rust and npm package names; the character lab's saved key; the
   game README, the brief's title and decision log, and the journey header.
5. Leave verbatim prompts, old receipts and commit history unchanged, and leave
   another session's untracked articles alone.
