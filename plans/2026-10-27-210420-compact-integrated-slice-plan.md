# Compact integrated slice plan

Linked prompts file: `prompts/2026-10-27-210420-compact-integrated-slice-prompts.md`  
Linked learnings file: `learnings/2026-10-27-210420-compact-integrated-slice-learnings.md`

## Goal

Use a compact floor plan and existing modular art to build an integrated camp-to-castle game loop.

## Approach

1. Record the playable footprint and placements in `game/docs/compact-floor-plan.md`.
2. Render the selected rigged character, local AI allies, and static Bloom/Bramble enemy candidates at simulation-owned positions.
3. Place the existing gate, trees and camp canvas around an unobstructed route, showing the gate opening when combat state permits.
4. Preserve class rules, controls and HUD; adjust the camera and short-landscape layout after visual inspection.
5. Verify committed builds in isolation, compare runtime with the chosen reference and document remaining gaps.
