# Gate kit kickoff evidence

The garden gate is an initial representative environment export, not a finished game level. The reference was generated by fal GPT Image 2.5 Flare; its prompt and charge receipt are alongside it. `gate-reimport-scale.jpg` shows the exported GLB reimported in a clean Blender process with a **1.6 m proxy**, not the actual player character. `gate-turnaround.jpg` shows the source from four angles.

Rebuild from the repository root:

```sh
'/Applications/Blender.app/Contents/MacOS/Blender' --background --python game/assets/blender/environment/build_gate.py
'/Applications/Blender.app/Contents/MacOS/Blender' --background --python game/assets/blender/environment/verify_gate.py
```

The reimport measured 6.4 m wide × 2.06 m deep × 5.57 m tall, with its base at zero. The geometry was authored around a 2.6 m wide arch with a 3.0 m apex. Inventory: eight material meshes, 9,552 declared triangles and no required extensions or external resources. Inventory and reimport checks do not establish engine appearance, playable collision or actual draw counts.

Compared with the generated reference, the gate keeps the twin blue roofs, arched doors, stonework and blue accents, but uses simpler flat-color stone and roofs; it omits windows, flags, vines and detailed ironwork. The gate is currently a static closed model: it does not animate or open. The real character has not yet been placed next to it. Runtime load and matched-camera visual review remain pending.

Cost: $0.0370 fal; no Tripo credits were spent on the procedural environment.
